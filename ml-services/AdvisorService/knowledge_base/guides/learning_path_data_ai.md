## Foundations
Learn Python, SQL, basic statistics and linear algebra ideas. Practise cleaning and exploring data with pandas and NumPy.

## Analysis and visualisation
Learn to ask a question, analyse a dataset and present the result with charts or a dashboard (Power BI, Tableau or Python libraries).

## Machine learning
Learn supervised and unsupervised learning, train/test splits, evaluation metrics and overfitting using scikit-learn. Then try one deep learning framework (PyTorch or TensorFlow).

## Data engineering basics
Learn how data moves: ETL, simple pipelines, databases and data warehouses. Know what an API and a batch job are.

## Projects
Publish two end-to-end projects: data, method, result and honest limitations. Explain the model choices in plain language.
