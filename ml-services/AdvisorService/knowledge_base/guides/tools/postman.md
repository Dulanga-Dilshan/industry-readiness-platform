## What it is
Postman is a tool for sending HTTP requests to an API and inspecting the responses. Developers and QA engineers use it to try out and test REST APIs without writing a client first.

## How to start
Install Postman, create a collection, add a request (method, URL, headers, body), send it and read the status code and JSON body. Save requests in a collection and use environments for variables such as the base URL.
