## Foundations
Learn networking (TCP/IP, DNS, HTTP), Linux and one scripting language. Security work builds on understanding how normal systems behave.

## Core security concepts
Study the CIA triad, authentication and authorisation, cryptography basics, common web vulnerabilities (OWASP Top 10) and secure coding.

## Hands-on practice
Use legal practice labs and capture-the-flag platforms. Learn a traffic analysis tool such as Wireshark and a vulnerability scanner. Only test systems you own or have written permission to test.

## Defensive skills
Learn log analysis, SIEM concepts, incident response steps and basic hardening of Linux and Windows systems.
