## Foundations
Get comfortable with Linux, the command line, networking basics (DNS, HTTP, ports) and Git. Learn one scripting language (Bash or Python).

## Containers
Learn Docker: images, containers, volumes, networks and docker compose. Containerise a small web app and its database.

## CI/CD
Build a pipeline that tests, builds and deploys an app (GitHub Actions or Jenkins). Learn what a deployment strategy is (rolling, blue/green).

## Cloud and infrastructure as code
Pick one cloud (AWS, Azure or GCP) and learn compute, storage, networking and IAM. Describe infrastructure with Terraform. (verify: which cloud local employers use most)

## Orchestration and monitoring
Learn Kubernetes basics (pods, deployments, services) and basic monitoring and logging.
