## What it is
Docker packages an application and its dependencies into a container image so it runs the same way on any machine with Docker.

## How to start
Write a Dockerfile for a small app, build the image, run a container, then use docker compose to run the app together with a database. Learn images versus containers, volumes and port mapping.

## Where it appears in jobs
DevOps, cloud and backend roles commonly list it. (verify: frequency in the scraped postings)
