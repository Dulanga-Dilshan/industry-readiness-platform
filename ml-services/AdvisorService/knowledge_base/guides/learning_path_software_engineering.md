## Foundations
Learn one language well first (Python, Java or JavaScript/TypeScript). Practise data structures, basic algorithms, reading error messages and debugging. Learn Git and GitHub early and use them for every project.

## Web and backend basics
Build a small REST API with a mainstream framework (for example Spring Boot, Django/FastAPI or Node.js) and a relational database (SQL). Understand HTTP, JSON, authentication basics and how to test an API with a tool such as Postman.

## Frontend basics
Learn HTML, CSS and JavaScript, then one framework (React, Angular or Vue). Build one complete project that talks to your own API.

## Quality and teamwork
Write unit tests, learn code review habits, and practise Agile/Scrum vocabulary. Add a simple CI pipeline to a project (for example GitHub Actions).

## Portfolio
Publish two or three finished projects with a clear README, screenshots and a live demo link. Employers can check these quickly. (verify: what local recruiters look at first)
