## Foundations
Learn the OSI and TCP/IP models, IP addressing and subnetting, Ethernet, switching, routing and common protocols (DNS, DHCP, HTTP).

## Hands-on labs
Use a network simulator to build small networks with VLANs, static and dynamic routing, ACLs and NAT. Document each lab.

## Servers and systems
Learn Linux and Windows Server administration, virtualisation and basic storage and backup ideas.

## Security and monitoring
Learn firewalls, VPNs and basic network monitoring and troubleshooting methods.
